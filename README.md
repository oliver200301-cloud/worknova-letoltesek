# Worknova letöltések

Ebben a tárolóban csak a Worknova programok **telepítői** találhatók (kiadásként). A forráskód privát.

| Program | Verzió | SHA-256 |
|---|---|---|
| WASILY (Windows x64) | 2.2.5 | `64d2b44c97419167eadd88f6736054826aa7d917209557c75ec070a4d2ed4fcc` |
| Wingly (Windows) | 0.3.0 | `0b132ff2640406e311f929108df660c2153aefc745416b3ab440fcac79b98d6a` |

**Fontos:** a telepítők jelenleg nem rendelkeznek kódaláírással, ezért a Windows SmartScreen figyelmeztetést mutathat („Ismeretlen kiadó”). Letöltés után ellenőrizd az SHA-256 értéket: `certutil -hashfile <fájl> SHA256`.

Letöltés: Releases oldal, vagy a https://worknova.hu/letoltesek oldal.
